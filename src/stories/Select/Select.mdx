# Select

A flexible dropdown select component with a light green theme. Supports single selection, multi-select with checkboxes, real-time search filtering, and collapsible nested option groups. All variants are composable — searchable and multiple can be combined freely.

## Import

```tsx
import { Select } from '@modulr-ui/core';
import '@modulr-ui/core/styles';
```

## Basic usage

```tsx
<Select
  options={[
    { label: 'Apple', value: 'apple' },
    { label: 'Banana', value: 'banana' },
    { label: 'Cherry', value: 'cherry' },
  ]}
  label="Select a fruit"
  onChange={(value) => console.log(value)}
/>
```

## Multi-select with checkboxes

Set `multiple` to allow selecting several options at once. Each option renders a green checkbox. The trigger shows a count badge when items are selected. The dropdown footer has **Clear all** and **Apply** buttons.

## Searchable

Set `searchable` to add a search field at the top of the dropdown. The input auto-focuses on open and filters options by label in real time. A clear button appears when the query is non-empty.

## Grouped options

Options with a `children` array render as collapsible group headers. Clicking the header expands or collapses it; child options are indented beneath it. Group headers are not selectable.

```tsx
const options = [
  {
    label: 'Fruits',
    value: 'fruits-group',
    children: [
      { label: 'Apple', value: 'apple' },
      { label: 'Banana', value: 'banana' },
    ],
  },
  {
    label: 'Vegetables',
    value: 'vegetables-group',
    children: [
      { label: 'Carrot', value: 'carrot' },
    ],
  },
];
```
